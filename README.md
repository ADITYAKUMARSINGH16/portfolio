## 🚀 Running Locally

> **Note**: Because this application uses native JavaScript ES Modules (`type="module"`), it must be served through a local HTTP server rather than opened directly as a `file://` path to avoid browser CORS restrictions.

### Option 1: Python (Recommended)
```bash
python -m http.server 8080
```
Open [http://localhost:8080](http://localhost:8080) in your browser.

### Option 2: Node.js / npx
With live reload:
```bash
npx live-server
```
Or with a static server:
```bash
npx serve .
```

### Option 3: VS Code / IDE Live Server Extension
1. Install the **Live Server** extension in VS Code.
2. Right-click on `index.html` and select **"Open with Live Server"**.
